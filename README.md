
# Excel Formula Hub 📊

Excel Formula Hub is a Python Streamlit website for learning and practicing Excel formulas.

## Features

- Home Dashboard
- All Excel Formulas
- Formula Search
- Formula Categories
- Learning Courses
- Practice Quiz
- Formula Playground
- Download Resources
- About Us

## Technologies

- Python
- Streamlit
- Pandas

## Installation

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app.py
```
